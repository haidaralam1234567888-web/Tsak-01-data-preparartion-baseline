
# Task 01: Data Preparation and Baseline

## Objective
To prepare a public dataset and build a simple machine learning baseline.

## Dataset
The Iris dataset contains 150 samples, four input features and three flower species.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Google Colab

## Methodology
1. Loaded and inspected the Iris dataset.
2. Split the dataset into 80% training and 20% testing sets.
3. Evaluated a DummyClassifier baseline.
4. Trained a Logistic Regression model.
5. Evaluated the model using accuracy and a classification report.

## Results
- Baseline accuracy: 33.33%
- Logistic Regression accuracy: 96.67%

## Conclusion
Logistic Regression performed better than the baseline on the held-out test dataset.

## How to Run
Open the notebook in Google Colab and run the cells from top to bottom.
